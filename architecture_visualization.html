Teaching Note on LangGraph interrupt(): Unlike traditional multithreading where worker processes sleep or poll, LangGraph's interrupt() immediately halts execution and serializes channel data to SQLite. No CPU or RAM is consumed while waiting for the human to review.

Complete Function-by-Function Breakdown

Reference table of every module, class, and function in src/ and the project root.

main.py (Project Root) Server Entrypoint

main(): Boots the Uvicorn server on host 0.0.0.0 and port 8000 targeting "src.api:app" with hot-reloading.

src/config.py Settings Module

Settings(BaseSettings): Reads .env file into typed properties (Gemini keys, LinkedIn tokens, active version 202511, SMTP, SQLite path).

settings = Settings(): Global singleton instance.

src/state.py State Models

WorkflowStatus(Enum): States: drafting, waiting_for_approval, revising, published, error.

RevisionHistoryItem(TypedDict): Tracks revision number, draft string, human feedback, and timestamp.

PostState(TypedDict): LangGraph shared channel state holding info, draft, approved, post_id, post_url, error, and history.

src/llm.py LLM Factory

get_llm() -> ChatOpenAI: Factory returning Google Gemini 2.5 Flash via OpenAI-compatible endpoint (https://generativelanguage.googleapis.com/v1beta/openai/) with fallback to Groq and OpenAI.

src/linkedin.py LinkedIn REST Client

verify_credentials(): Checks token validity against https://api.linkedin.com/v2/userinfo.

publish_post(commentary, dry_run): Makes POST request to https://api.linkedin.com/rest/posts with version 202511, returns post URN and public feed link.

src/notifier.py Notification Service

NotificationStore: In-memory & UI accessible list of dispatched review notifications.

send_draft_ready_notification(...): Sends email with review URL and 1-click approve link containing the message: "Your draft is ready. If you are okay with this, you can just approve or if you need any changes, you can just provide the changes."

src/checkpointer.py Persistent Checkpointer

get_checkpointer() -> SqliteSaver: Initializes LangGraph's SqliteSaver connected to data/checkpoints.db.

save_post_metadata(...) & get_all_posts_metadata(): High-speed index of thread metadata for dashboard cards.

src/nodes.py Workflow Graph Nodes

generate_draft_node(state): Prompts Gemini and creates initial post.

ask_for_feedback_node(state): Dispatches notification, then executes interrupt() to pause the graph.

decide_next(state): Conditional router returning post_to_linkedin or revise_draft.

revise_draft_node(state): Prompts Gemini with reviewer critique and generates new draft.

post_to_linkedin_node(state): Publishes final text to LinkedIn REST API.

src/workflow.py Workflow Orchestrator

build_workflow_graph(): Assembles nodes, edges, conditional edges, and compiles with SqliteSaver.

start_post_workflow(...): Starts execution up to the first interrupt.

resume_post_workflow(thread_id, approved, feedback): Resumes interrupted thread with Command(resume=...).

get_post_details(thread_id): Fetches live snapshot from SQLite.

src/api.py FastAPI Application

GET /: Renders studio dashboard (index.html).

GET /review/{thread_id}: Renders dedicated review interface (review.html).

POST /api/posts: Triggers post creation workflow.

POST /api/posts/{thread_id}/review: Handles review decision (approve or revise).

GET /api/posts/{thread_id}/quick-approve: 1-click email approve link.

GET /api/health: Healthcheck for EC2 and Docker.

Why SQLite Persistence is Essential for HITL

A step-by-step lecture walkthrough of what happens when human review takes days.

Day 1: 10:00 AM

Post Generation Initiated

A user or scheduled cron job calls POST /api/posts. Gemini 2.5 Flash writes the post commentary. LangGraph reaches ask_for_feedback_node and calls interrupt().

Action: Full graph channels are serialized to data/checkpoints.db. Email dispatched.
Day 3: 04:00 PM

Server Maintenance / Reboot

The Docker container is restarted or updated. If we were using an in-memory saver, the workflow thread would be wiped out.

Persistence Guarantee: SqliteSaver holds the complete interrupted state safe on disk.
Day 6: 09:30 AM

Reviewer Opens Email

The human reviewer clicks the review link in their email. FastAPI queries data/checkpoints.db, loads the exact draft and revision history, and renders the review card in the browser.

Day 6: 09:35 AM

Reviewer Clicks "Approve & Post"

FastAPI calls graph.invoke(Command(resume={'approved': True}), config={'configurable': {'thread_id': id}}).

Output: LinkedIn REST API returns HTTP 201 Created with live post ID urn:li:share:...!
